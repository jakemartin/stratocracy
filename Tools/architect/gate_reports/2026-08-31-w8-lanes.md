## Open, named rather than closed

**The baseline gap.** Rounds 1–5 gated *untracked working trees* in each lane's own worktree.
"The committed bytes are the bytes gated" is therefore **unfalsifiable from any checkout** — an
edit made between the last gate and the commit is invisible to every instrument this project has,
including this file. Round 5 said so explicitly about its own round-1→round-2 comparison (no
before/after hash existed for the untracked test files). The structural fix is to persist each
round's gate report, and any hash it depends on, in the same pass that produces it — this file
does that only retroactively, for six rounds that already happened.
